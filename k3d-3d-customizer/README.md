# K3D 3D Customizer

إضافة ووردبريس مستقلة (مش جزء من ثيم K3D Shop) بتضيف معاينة 3D حية (Three.js) لتخصيص المنتجات - العميل بيكتب اسم أو رقم، وبيشوفه بيتحول لمجسم فوري يقدر يدوّره ويزوّمه، قبل ما يضيفه للسلة.

## المتطلبات

- WooCommerce مفعّل.
- المعاينة بتحمّل Three.js من CDN (jsdelivr) في متصفح الزائر مباشرة - مفيهاش أي build step أو npm install على السيرفر.

## التفعيل

1. **Plugins > Add New > Upload Plugin** → ارفع ملف الـzip، وفعّل.
2. هيظهر عنصر **"K3D 3D Customizer"** في القائمة الجانبية لووردبريس (بعد "المنتجات") - منه تقدر تشوف كل المنتجات المفعّل عليها المعاينة، وأنواع التصاميم المتاحة.
3. الصفحة الرئيسية (لو ثيم K3D Shop مفعّل) هتستخدم المعاينة تلقائيًا كهيرو تفاعلي (اسم بيتحول لمجسم). **لو مش شايفها**: تأكد إن الإضافة دي فعلاً مفعّلة من Plugins، وإن ووكومرس مفعّل، وافتح Console المتصفح (F12) في الصفحة الرئيسية تشوف لو فيه خطأ JS (زي فشل تحميل Three.js من الـCDN لو فيه حاجب/فايروول بيمنع jsdelivr.net).
4. لأي منتج عايز تفعّل عليه المعاينة: افتح **تعديل المنتج**، هتلاقي بوكس "المعاينة 3D الحية" في السايدبار → فعّلها → اختار نوع التصميم (اسم / لوحة-رقم) → احفظ.
5. النص/اللون اللي العميل يختارهم بيتسجلوا تلقائيًا مع الطلب نفسه - هتلاقيهم في: تفاصيل عنصر السلة، صفحة الطلب في لوحة التحكم، وإيميلات تأكيد الطلب (للعميل وللأدمن). **الإضافة معملتش أي ملف طباعة (STL) - دورها بس المعاينة للعميل وتسجيل اختياره، وباقي الشغل (تجهيز الملف والطباعة) بتعمله انت يدويًا من نفس المعلومات دي.**

## إضافة تصميم جديد مستقبلًا (بدون ما تلمس الكود الحالي)

كل تصميم = ملف JS بيسجل نفسه + وصف PHP بسيط. الخطوات:

1. اعمل ملف جديد `assets/js/designs/اسم-التصميم.js` بنفس شكل `name.js`/`plate.js` - المطلوب بس `registerDesign('مفتاح-فريد', function({THREE, scene, value, colorHex}) { ... return {object3D, update(newValue, newColorHex), dispose()} })`.
2. سجّل التصميم في `includes/designs.php` (أو أفضل: من إضافة/mu-plugin منفصلة عن طريق فلتر `k3d_3dc_designs` - من غير ما تعدّل ملفات البلجن الأساسية) بنفس شكل التصاميم الموجودة (label, default_value, colors...).
3. ضيف سطر `import(cfg.moduleBaseUrl + 'designs/اسم-التصميم.js')` في `assets/js/init.js`.

التصميم الجديد هيظهر تلقائيًا في قائمة "نوع التصميم" في صفحة تعديل أي منتج.

## ملاحظة عن النص العربي

تصميم "اسم مجسم" بيرسم النص على canvas 2D (المتصفح نفسه بيتولى تشكيل الحروف العربية المتصلة صح) وبعدين يحوّله لسطح 3D بإضاءة تدي إحساس البروز - ده أضمن تقنيًا من عمل extrude لكل حرف عربي لوحده جوه Three.js (اللي بيكسر شكل الحروف المتصلة). تصميم "لوحة/رقم" بيستخدم extrude حقيقي لأن الأرقام مالهاش مشكلة تشكيل.
